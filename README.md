# predictive-maintenance-project
Hybrid Classification and Regression Model for Predictive Maintenance in Smart Factories using Machine Learning and IoT Sensor Data.
A machine learning-based predictive maintenance system designed to monitor industrial machine conditions and predict failures before they occur. This project combines classification and regression techniques to improve maintenance planning, reduce downtime, and increase operational efficiency in smart factories.

#PROJECT OVERVIEW:

Predictive maintenance helps industries detect machine failures early using sensor data and machine learning algorithms. This project focuses on:

Monitoring machine health using sensor data.
Detecting abnormal machine conditions.
Predicting Remaining Useful Life (RUL).
Reducing maintenance costs and downtime.
Improving reliability of industrial systems.
